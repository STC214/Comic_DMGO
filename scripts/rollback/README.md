# 历史回滚脚本

这一目录保存特定旧版本的回滚脚本，不是最新发布的回滚入口。脚本默认只检查备份，不会覆盖目标。例如，从项目根目录检查某个旧版备份：

```powershell
.\scripts\rollback\rollback-go-ui-title-mark.ps1
```

只有显式添加 `-Apply` 才会恢复文件。先读脚本并确认版本、备份和目标路径：部分历史脚本指向固定的生产目录，另一些恢复本地构建产物或文档。缺少旧备份时应停止，不要用其他版本的备份替代。

对于近期更新，优先使用该次发布验证记录所指向的版本专用回滚脚本。

`rollback-gitignore.ps1` 和 `rollback-documentation-update.ps1` 的 `-Apply` 只适用于对应的旧目录布局；新布局下可以验证备份，但不会恢复旧的根目录文件。
