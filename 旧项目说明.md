# Comic Downloader

A Windows comic downloader focused on `myreadingmanga.info`.

The app is a Go/Fyne desktop program. Go owns task routing, persistence, worker lifecycle, progress aggregation, Chromium setup, and task-scoped browser profiles. Python is kept only for the `myreadingmanga` DrissionPage worker.

## Current Contract

- The frontend submits `url` and `downloadRoot`.
- The filter routes only `myreadingmanga.info` URLs to the `myreadingmanga` worker.
- Browser tasks run with task-scoped profile copies under `runtime/browser-profiles/`.
- `myreadingmanga` opens the original task URL visibly only when its initial headless check reports verification.
- When verification succeeds, that visible browser closes, its profile refreshes both the machine default and `verified-base`, and the original task resumes in a new headless browser.
- The UI can import an old `comic_downloader_state.json`; import keeps only `myreadingmanga` tasks, skips retired-site tasks, deduplicates by URL, and fixes known completion-text mojibake.
- Other historical workers (`zeri`, `nyahentai`, and `hentai2`) have been removed from this project.

## Project Layout

- `main.go` - Go launcher, task manager, worker bridge, persistence, and lifecycle control.
- `site_backend.go` - `myreadingmanga` routing, dispatch, progress file handling, and result collation.
- `fyne_ui_windows.go` - primary Windows/Fyne UI.
- `workers/myreadingmanga_drissionpage/main.py` - active site worker.
- `workers/download_middleware.py` - shared image download helpers used by the active worker.
- `tools/browser_launch.py` - shared DrissionPage/Chromium launch helpers.
- `runtime/go.mod` - module boundary so `go test ./...` does not scan runtime browser profiles.
- `runtime/` - ignored runtime resources, state, Chromium, Python, and task-scoped browser profiles.
- `download/` - default download root.
- `logs/` - log output.
- `docs/` - contract, checklist, and audit notes.

## Worker Check

Manual verification checkpoint:

```powershell
python ./workers/myreadingmanga_drissionpage/main.py --url "https://myreadingmanga.info/genre/shota/" --checkpoint
```

Content flow:

```powershell
python ./workers/myreadingmanga_drissionpage/main.py --url "https://myreadingmanga.info/suikadonburi-wotame-can-you-pee-well-eng/" --download --download-root ./tmp/myreadingmanga_test
```

## History Import

Use the `导入历史记录` button in the top toolbar to select an old `comic_downloader_state.json`.
The picker is the Windows native Explorer-style file dialog.

Import behavior:

- Only `myreadingmanga` tasks are imported.
- `zeri`, `nyahentai`, `hentai2`, and unknown-site tasks are skipped.
- Existing tasks are deduplicated by canonical URL.
- Queued or running imported tasks are restored as paused so import does not start downloads automatically.
- Known corrupted completion-status text is normalized to `完成`.

## Runtime Notes

- `runtime/python/python.exe` and `runtime/chromium/chrome.exe` are bundled with the portable build.
- Release scripts only bundle a Python environment that can import `DrissionPage`; set `COMIC_DOWNLOADER_PYTHON_HOME` if auto-detection should use a specific environment.
- `runtime/comic_downloader_state.json` stores UI state.
- `runtime/browser-profiles/` stores task-scoped browser profile copies.
- Runtime data is ignored by git except `runtime/go.mod`, which protects `go test ./...` from inaccessible browser profile directories.
